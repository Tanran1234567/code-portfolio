# Python、计算机视觉与算法实践

这组文件包含按学习阶段整理的基础练习，以及目标检测、语义分割、图像分类和五子棋应用。不同子目录使用的框架、年代和数据依赖不同，应分别准备环境，不能把空的原 `requirements.txt` 当作可用的统一依赖清单。

## 按文件夹介绍

| 子目录 | 实现内容 | 能力点 |
|---|---|---|
| `day1`、`day4` | NumPy 神经网络与 RNN 基础练习 | 数组计算、前向传播与序列建模概念 |
| `day5` | 读图、灰度/通道、直方图均衡、阈值、翻转和仿射变换 | OpenCV 图像预处理 |
| `day6` | 缩放/裁剪、透视、形态学、滤波、边缘与轮廓 | 图像特征处理 |
| `day7` | 几何拟合、纸张/零件示例、视频和摄像头处理 | 图像测量与视频 I/O |
| `day8`、`day9` | Paddle 张量、回归、房价预测、模型保存加载；`fruits_code` 为水果分类 | 数据读取、训练与推理流程 |
| `day10`、`day11` | PyTorch 张量、自动微分、回归、ModuleList/Sequential、Dataset | 深度学习工程基础 |
| `day12` | TensorDataset、LeNet/CIFAR-10 图像分类 | 网络定义、批处理与训练 |
| `day17` | LabelMe 标注转 mask | 分割标签预处理 |
| `DeepLab3_plus` | DeepLabV3+ 网络、数据读取、loss、训练、评估、推理和导出 | 语义分割完整流程 |
| `yolo_od` | Ultralytics 训练/评估/推理、Paddle YOLOv3 实现、PyQt 检测界面 | 目标检测与桌面界面集成 |
| `五子棋` | 15×15 棋盘、启发式评分、候选落点、Minimax 与 alpha-beta 剪枝 | 搜索算法和交互程序 |
| `fruits` | `obj_svm.py` 特征/分类相关练习 | 传统机器学习实践 |
| `RSP` | 保留数据说明与类别配置，未发布图像和标签全集 | 外部数据集组织与来源说明 |

原来的 `data/`、`test_data/`、`cifar-10-batches-py/` 是外部数据或练习素材；`model/`、`models/` 是模型资源。公开版本排除这些资源及权重、视频、缓存，需要按脚本路径自行准备。

## 推荐展示入口

**五子棋（无第三方依赖）**

```bash
python 五子棋/wuziqi.py
```

在命令行输入行列坐标，输入 `q` 退出。棋盘尺寸 15、默认搜索深度 3，限制候选位置以控制计算量。本次验证了基础规则和深度 1 的搜索合法性，未进行完整棋力测试。

**目标检测界面**

`yolo_od/yolo11_od.py` 使用 PyQt5、OpenCV、PyTorch 和 Ultralytics，支持图片、视频和摄像头输入。需准备脚本指定的 `yolo11n.pt` 权重及本地显示环境。代码中保留了教学材料相关文字，不将界面素材视为原创声明。

**语义分割 / 旧版 Paddle 练习**

包含 `paddle.fluid` 旧接口，需匹配相应版本或迁移后运行。这里保留原练习快照，不承诺在最新 Paddle 环境直接运行。
